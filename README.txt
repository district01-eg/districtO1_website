districtO1 website

1) Open index.html to preview the website.
2) Replace demo product names, photos, and prices with your real products.
3) WhatsApp order link is set to the number you supplied: +20 114 376 1413.
4) Publish for free:
   - Create an account at https://app.netlify.com/drop
   - Drag the whole website folder (or the ZIP) into the deploy area.
   - Netlify will publish it and give you a public .netlify.app link.

This is a front-end catalogue demo. It does not yet include checkout, online payments,
inventory management, or a working newsletter backend. Demo products/prices are placeholders.
